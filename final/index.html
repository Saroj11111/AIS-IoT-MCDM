Triantaphyllou & Sánchez (1997)

How far can one weight move before a ranking changes?

δ′ = smallest change in one criterion weight, as a % of that weight, that swaps two alternatives. Negative = the weight must rise; positive = it must fall. N/F = no change can swap them. Smaller |δ′| = more sensitive. Studies with identical rows are analysed as one group (e.g. S11/S16).

Decision

Contenders = the top 3 of the final ranking plus every study that is first in at least one ranking. For each pair of contenders and each ranking: who is ahead, and how big a weight change (δ′) would reverse that. The best alternative leads its rivals most often; a tie is broken by whose weakest lead needs the larger change.

AHP (three experts)

  1. Each expert gives 21 pairwise judgments (Saaty 1–9)
  2. Build the 7 × 7 matrix (reverse = reciprocal)
  3. Geometric mean of each row, divided by the total → weights
  4. Consistency ratio CR = CI / RI must be below 0.10

CRITIC

  1. Normalise each column: (x − min)/(max − min)
  2. Standard deviation of each column (spread)
  3. Correlation matrix; conflict = Σ(1 − ρ)
  4. C = spread × conflict; weight = C / ΣC

Entropy

  1. Shares p = x / column total
  2. E = −(1/ln n) Σ p ln p
  3. Divergence 1 − E
  4. Weight = (1 − E) / Σ(1 − E)

TOPSIS

  1. Vector-normalise: x / √Σx²
  2. Multiply by the weights
  3. Ideal best A+ and worst A−
  4. Distances D+, D−; CC = D− / (D+ + D−)

VIKOR

  1. Distance from best: (f* − x)/(f* − f−)
  2. S = weighted sum, R = largest weighted term
  3. Q = v·S′ + (1 − v)·R′ (rescaled)
  4. Check advantage (DQ = 1/(n−1)) and stability

PROMETHEE I

  1. Same Φ+ and Φ− as PROMETHEE II
  2. a outranks b if Φ+(a) ≥ Φ+(b) and Φ−(a) ≤ Φ−(b), one strictly
  3. Equal on both = indifferent; flows disagree = incomparable
  4. Partial ranking in levels (no one outranks level 1)

PROMETHEE II

  1. Usual preference: P = 1 if a beats b on a criterion
  2. π(a,b) = Σ w·P
  3. Φ+ = row sum/(n−1), Φ− = column sum/(n−1)
  4. Net flow Φ = Φ+ − Φ−

Final ranking and decision

  1. Six rankings on the same 1–20 scale (PROMETHEE I levels → ranks)
  2. Final rank = rank of the average of the six
  3. Sensitivity analysis on all six rankings
  4. Best = the contender that holds its lead against the others most often

Notes

All calculations run in Python. run_frontend.py passes the table to frontend_api.py, which calls the functions in the scripts (AHP weight.py, TOPSIS-AHP method.py, Final ranking.py, Sensitivity analysis.py and the rest) and sends the results back. This page only displays them.

Sensitivity: PROMETHEE II net flow is a weighted sum, so the closed-form formula δ = (Pⱼ − Pᵢ)/(aⱼₖ − aᵢₖ) is used, with δ < wₖ required. PROMETHEE I applies the same formula to Φ+ and Φ− separately. TOPSIS and VIKOR are not weighted sums, so δ is found by moving the weight step by step until the pair swaps.

Case study: Aldhaheri et al. (2020), Journal of Network and Computer Applications, 157, 102537. Sensitivity method: Triantaphyllou & Sánchez (1997), Decision Sciences, 28(1), 151–194.
