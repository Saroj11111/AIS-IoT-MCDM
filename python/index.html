How far can one weight move before the ranking changes?

δ′ = smallest change in one criterion weight, as a % of that weight, that swaps two alternatives. Negative = the weight must rise; positive = it must fall. N/F = no change can swap them. Smaller |δ′| = more sensitive.

AHP

  1. Pairwise comparison matrix from the judgments
  2. Multiply across each row, take the 7th root (geometric mean)
  3. Divide by the total → weights
  4. Consistency ratio CR = CI / RI must be below 0.10

CRITIC

  1. Normalise each column: (x − min)/(max − min)
  2. Standard deviation of each column (spread)
  3. Correlation matrix; conflict = Σ(1 − ρ)
  4. C = spread × conflict; weight = C / ΣC

Entropy

  1. Shares p = x / column total
  2. E = −(1/ln n) Σ p ln p
  3. Divergence 1 − E
  4. Weight = (1 − E) / Σ(1 − E)

TOPSIS

  1. Vector-normalise: x / √Σx²
  2. Multiply by the weights
  3. Ideal best A+ and worst A−
  4. Distances D+, D−; CC = D− / (D+ + D−)

VIKOR

  1. Distance from best: (f* − x)/(f* − f−)
  2. S = weighted sum, R = largest weighted term
  3. Q = v·S′ + (1 − v)·R′ (rescaled)
  4. Check advantage (DQ = 1/(n−1)) and stability

PROMETHEE I

  1. Same Φ+ and Φ− as PROMETHEE II
  2. a outranks b if Φ+(a) ≥ Φ+(b) and Φ−(a) ≤ Φ−(b), one strictly
  3. Equal on both = indifferent; flows disagree = incomparable
  4. Partial ranking in levels (no one outranks level 1)

PROMETHEE II

  1. Usual preference: P = 1 if a beats b on a criterion
  2. π(a,b) = Σ w·P
  3. Φ+ = row sum/(n−1), Φ− = column sum/(n−1)
  4. Net flow Φ = Φ+ − Φ−

Notes

All calculations run in this page and use the same formulas as the Excel workbook and the Python scripts; the three give identical results on the sample data.

Sensitivity: PROMETHEE II net flow is a weighted sum, so the closed-form formula δ = (Pⱼ − Pᵢ)/(aⱼₖ − aᵢₖ) is used, with δ < wₖ required for feasibility. TOPSIS and VIKOR are not weighted sums, so δ is found by moving the weight step by step until the pair swaps.

Case study: Aldhaheri et al. (2020), Journal of Network and Computer Applications, 157, 102537. Sensitivity method: Triantaphyllou & Sánchez (1997), Decision Sciences, 28(1), 151–194.
